## Two ways to use this zip

**A. Review the diff, then merge (recommended).**
The zip keeps `.git`, so from the project root:

```bash
git status          # shows exactly which files the upgrade touched
git diff --stat
git diff arb/executor.py
```

Or apply the standalone patch to your own checkout:

```bash
git apply --check upgrade-2026-09-30.patch   # verify it applies
git apply upgrade-2026-09-30.patch
```

**B. Replace your copy.** The tree is complete and self-contained apart from
`.git/config` (stripped) and caches. Re-run the two suites after either route.

Note: the patch is code and docs only. `logs/arb_survey*.jsonl` (the evidence
`NOTES-production.md` cites) are gitignored, so they are in the full tree but not
in the patch. `build/` is likewise not shipped — it regenerates on first compile.

## Added later the same day: the real-execution path

Two things stood between "the code is finished" and "a trade can be sent", and
neither was contract logic:

| file | change |
|---|---|
| `arb/preflight.py` + `arb preflight` | **new** — GO/NO-GO against the live chain: market gate from the survey logs, deployment FRESHNESS (runtime bytecode vs the current ABI's selectors), wallet funding and ownership, gas price vs market, base-fee headroom, venue/token usability, relay reachability |
| `arb/deployer.py` | `probe_relay()` — asks a private relay for a block number before you depend on it, so a typo surfaces at preflight rather than at broadcast |
| `scripts/upgrade_proof.py` | **new** — deploys the current artifact to a fresh mainnet fork and exercises BOTH directions, prints the gas, verifies balances move by exactly the profit, checks a non-owner cannot withdraw, and sweeps clean. Ends GO or NO-GO |
| `docs/real-execution-runbook.md` | **new** — wallet, deploy, micro-drill at 0.1 USDT, and the size-up ladder |

Two findings worth carrying forward:

- **Execution costs 350,338 gas** (V2-first) and **286,804** (V3-first), measured on
  a fork — materially below the 600,000 the no-contract fallback assumes. Deploy
  is 1,962,419. The floor already uses a live `estimateGas`; the fallback is a
  conservative over-estimate, which is the safe direction for a floor.
- **The model is only as good as the buy cost.** `scripts/upgrade_proof.py`'s first
  run reported a live V3-first edge of +25.85 bps because it had no exact-output
  quote for leg 1. With the honest quote the same block reads −5.72 gross. That is
  the same 2×-fee error that made an earlier survey look positive, now reproduced
  and fixed in the tool that reports it.

## Verify it works

```bash
python main.py selftest                    # 104/104 offline, no network
python -m pytest tests/ -q                 # 2 passed
python -m pytest tests/test_fork.py -q     # 9 passed (needs Foundry + archive RPC)
python scripts/upgrade_proof.py            # deploy + both directions on a mainnet fork
python main.py arb preflight --network bsc # GO/NO-GO, sends nothing
```

Fork tests need `anvil`. They probe for a BNB RPC that can serve archive state
(`api.zan.top`, `bsc-mainnet.public.blastapi.io` work; publicnode does not) and
skip cleanly if neither anvil nor a fork source is available.

## Read before trading

1. `NOTES-production.md` — findings, the cost floor table, the micro-drill runbook.
2. `docs/ev-private-memo.md` — why `--private` is the default posture.

**Headline: do not trade real size yet.** Not for code-quality reasons — the
contract is now proven end to end against real mainnet state — but because the
measured edge on the V2→V3 WBNB/USDT route is **negative** (−16 to −25 bps gross,
−33 to −42 bps net, at 1 WBNB). The earlier "profitable" survey rows were a
2×-fee modelling bug that is now fixed.
